# Mao Study Daily

每天学习一篇毛泽东文章：保存原文备查，并提供深入浅出的讲解。

## 文件结构

每篇文章按日期单独建立文件夹：

```text
YYYY-MM-DD-文章标题/
├── YYYY-MM-DD-文章标题-原文.md
├── YYYY-MM-DD-文章标题-讲解.md
└── YYYY-MM-DD-文章标题-讲解.pdf
```

个别日期可能另有“大字版”等辅助版本；早期文章若当时未生成 PDF，则只保留已有文件，不补造内容。
